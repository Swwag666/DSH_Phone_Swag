DSH PHONE — своя связка «телефон <-> DeepSeek Harness» (без облака AA)
===============================================================

ЧТО НУЖНО ДЛЯ РАБОТЫ
1. Windows.
2. Python 3.10+. Нет — ставится одной командой:
       winget install Python.Python.3.12
3. DeepSeek Harness Desktop, в нём ВКЛЮЧЁН плагин Agents Anywhere.
   Вход в учётку AA НЕ нужен — нужен только локальный мост плагина.
4. Tailscale на ПК и на телефоне, одним аккаунтом.

ЗАПУСК (на ПК)
1. Распакуй куда удобно.
2. Двойной клик run.bat.
3. В консоли появится токен (он же в config.json — файл создастся сам).

ПОДКЛЮЧЕНИЕ ТЕЛЕФОНА
1. Tailscale на телефоне, тот же аккаунт, что на ПК.
2. Узнай IP ПК: в консоли выполни
       tailscale ip -4
3. В браузере телефона открой:  http://<этот-IP>:8460/
4. Вставь токен. Появится список проектов и сессий.
5. «Поделиться» -> «На экран "Домой"» — будет иконка-приложение.

ЕСЛИ «мост отключён» / пусто
- Проверь, что DSH Desktop запущен и плагин Agents Anywhere включён.
- Файл моста:  ~/.dsh/agents-anywhere/bridge/endpoint.json  должен существовать.
- На телефоне после обновления приложения перезагрузи страницу (закрыть/открыть).
