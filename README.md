Управляй сессиями [DeepSeek Harness](https://github.com/deepseek-ai) со своего телефона - с дивана, из метро, с другого конца страны. DSH Phone поднимает на твоём ПК локальный узел, телефон цепляется к нему через [Tailscale](https://tailscale.com), и всё: список проектов, живой чат с агентом, ответы на апрувы, фото с камеры, голосовые. Никакого чужого облака, никаких серверов-посредников, никаких утечек. Данные не покидают твою сеть.

## Подключение за 4 шага

1. **Сеть.** Поставь [Tailscale](https://tailscale.com/download) на ПК и на телефон, войди одним аккаунтом. Приложение само определит IP ПК (сеть `100.x.x.x`) и покажет его в дашборде.
2. **Узел.** Запусти DSH Phone - сервер на порту `8460` поднимется сам. Рядом с треем живёт иконка, окно закрывается туда же.
3. **Линия.** На телефоне открой `http://<твой-IP>:8460` - появится экран входа.
4. **Ключ.** Скопируй токен из карточки «Ключ доступа» и вставь на телефоне. Жми «Поделиться → На экран Домой» - будет полноценное приложение-иконка.

> **Важно:** на ПК должен быть запущен DeepSeek Harness Desktop с включённым плагином Agents Anywhere - это единственная дверь, через которую узел говорит с агентом. Вход в учётку AA не нужен.

## Что умеет

- **Полный чат с агентом** - история сессий, markdown-рендер с таблицами и код-блоками, подсветка синтаксиса, typewriter-стриминг ответа
- **Отправка хода, стоп, повторы** - сообщение в занятую сессию не теряется: узел держит очередь и доставит, как агент освободится
- **Апрувы и вопросы агента** - кнопки прямо на телефоне, пуш-уведомление когда нужен твой ответ
- **Смена модели и прав доступа** - каталог моделей прямо из чата
- **Создание новых сессий** - выбор рабочей папки (cwd) с автоподсказкой
- **Фото с камеры и файлы** - HEIC и гигантские снимки конвертируются в JPEG на телефоне, до 50 МБ на вложение
- **Голос** - диктовка (Web Speech) или голосовое сообщение в чат
- **Оффлайн-кэш** - история и список сессий живут в localStorage, чат открывается мгновенно даже при плохой связи
- **Экспорт** - диалог в Markdown или JSON, через системный шеринг или файл
- **Мульти-устройства** - каждому телефону свой токен, свой коннектор и своё окно агента в DSH
- **Уведомления и непрочитанные** - бейджи, пуши о завершении хода, статистика (время хода, токены, оценка стоимости)

## Как это устроено

```
┌──────────────────────────── DSH Phone.exe ────────────────────────────┐
│                                                                        │
│  ┌──────────────┐   invoke (IPC)  ┌─────────────────────────────────┐ │
│  │ Окно (WebView)│ <────────────> │ Rust-ядро                        │ │
│  │ React + TS    │                │  конфиг · токены · устройства    │ │
│  └──────────────┘                 │  автостарт · tray · tailscale    │ │
│                                   └───────────────┬─────────────────┘ │
│                                                   │                    │
│                                   ┌───────────────▼─────────────────┐ │
│                                   │ axum-узел :8460                  │ │
│                                   │  PWA для телефона (вшита в exe)  │ │
│                                   │  API + long-poll события         │ │
│                                   │  whitelist RPC · allowlist IP    │ │
│                                   └───────────────┬─────────────────┘ │
└───────────────────────────────────────────────────┼────────────────────┘
                                                    │ JSON-RPC (TCP)
                                       ┌────────────▼────────────┐
                                       │ DeepSeek Harness Desktop │
                                       │ плагин Agents Anywhere   │
                                       └─────────────────────────┘
                                                    │ Tailscale (100.x)
                                              ┌─────▼─────┐
                                              │  Телефон  │  PWA в браузере
                                              └───────────┘
```

Один exe ~13 МБ. PWA-клиент вшит в бинарник при сборке - Python-гейтвей и Rust-узел раздают один и тот же клиент. Каждый телефон = отдельный коннектор моста, поэтому DSH Desktop открывает для каждого своё окно агента.

## Безопасность

- **Токен на каждое устройство** - крипто-рандом, сравнение constant-time. Смена ключа мгновенно отваливает старый. Токен передаётся в заголовке `X-Dsh-Token` (плюс совместимый query-фолбэк).
- **RPC-whitelist** - телефон может дёргать только 16 проверенных методов моста, никаких произвольных вызовов. (Фактический список - `RPC_WHITELIST` в `gateway.py` / `WHITELIST` в `server.rs`, тест фиксирует количество.)
- **IP-allowlist с CIDR** - белые списки адресов, кто в tailnet вообще достучится до узла. Пусто = все. Loopback всегда можно.
- **Узел слушает `0.0.0.0` из коробки** - это нужно для доступа из tailnet, но значит «доступен из каждой сети, к которой подключён ПК». Если `allowed_ips` пуст, узел при старте печатает предупреждение в консоль/лог. Заполни allowlist (например `100.64.0.0/10`) или поставь `listenHost` в конкретный адрес - узел честно биндится на него (Rust-версия читает `listen_host` из конфига, а не игнорирует его).
- **Опциональный TLS** - самоподписанный серт с SAN на tailnet-IP и sha256-отпечатком для пиннинга на телефоне.
- **Лимиты запросов** - тело до 80 МБ, заголовки до 100 строк / 64 КБ - одну «толстую» куку узел не положит. 10 неудачных попыток авторизации подряд = разрыв соединения (Python-гейтвей).
- **Staging самоочищается** - загруженные вложения больше не копятся вечно: узел раз в час подчищает файлы старше 7 дней (`stagingRetentionSecs` / `staging_retention_secs`, 0 = только ручная чистка).
- **Plain HTTP в tailnet - осознанный выбор.** Tailscale это WireGuard: трафик уже зашифрован между устройствами. TLS включается тумблером для параноиков (и для микрофона в Safari).

## Конфиг

`%APPDATA%\dsh-phone\config.json` (Python-гейтвей - рядом с `gateway.py`):

| Поле | Смысл |
|------|-------|
| `token` / `devices` | ключи устройств: основное + до 8 доп. телефонов |
| `listen_port` | порт HTTP-узла, по умолчанию `8460` |
| `tailscale_ip` | определяется сам, можно поправить руками |
| `allowed_ips` | белый список IP/CIDR |
| `staging_retention_secs` | срок жизни загруженных файлов в staging (по умолчанию 7 дней) |
| `tls_enabled` | TLS поверх tailnet |
| `start_hidden` | старт свёрнутым в трей |
| `bridge_endpoint_path` | файл моста AA (`~/.dsh/agents-anywhere/bridge/endpoint.json`) |

## Python-гейтвей - лёгкий вариант

Не хочешь ставить exe - есть [чистый Python-узел](dsh-phone/), только стандартная библиотека, ноль зависимостей:

```bat
cd dsh-phone
run.bat        :: или: python gateway.py
```

Токен появится в консоли и в `config.json`. Телефон подключается точно так же. Подходит для тонких клиентов, серверов и compulsive-минималистов.

## Траблшутинг

- **«Мост отключён» / пусто** - проверь, что DSH Desktop запущен и плагин Agents Anywhere включён; файл `~/.dsh/agents-anywhere/bridge/endpoint.json` должен существовать.
- **Телефон не видит узел** - запусти `tools/fix-firewall.bat` от администратора (правило для порта 8460), проверь что оба устройства в одном tailnet.
- **Связь отвалилась после включения/выключения WARP** - кнопка «Лечить связь» в конфиг-карточке: узел перевязывает сокеты tailscaled (`debug rebind` + `restun`).
- **После обновления приложения** - закрой и открой страницу на телефоне заново.

## Сборка из исходников

Нужно: Node 20+, pnpm, Rust stable (MSVC), VS Build Tools 2022 (C++).

```bash
cd dsh-phone-desktop
pnpm install
npx tauri build            # релиз: src-tauri/target/release/dsh-phone.exe + NSIS-сетап
npx tauri dev              # дев-режим с hot reload
```

> Собирай через `tauri build`, не голым `cargo build` - иначе фронтенд не вшьётся в бинарник.

## Тесты

```bash
cd dsh-phone && python -m unittest -v      # Python-гейтвей: HTTP-парсер, auth, интеграция
node dsh-phone/web/test-md.js               # PWA-рендер: экранирование, markdown
cd dsh-phone-desktop/src-tauri && cargo test  # Rust-ядро: whitelist, allow_ip, token_eq, staging
```

CI гоняет все три набора на каждый пуш и PR (`.github/workflows/ci.yml`).

> Бинарники в `releases/` не подписаны (нет код-сининг-сертификата). Если SmartScreen ругается - это ожидаемо; собери из исходников сам, команда выше.
