# DSH Phone

> Локальный мост между DSH Desktop и твоим телефоном. Один exe. Никакого облака. Только Tailscale и твой токен.

![stack](https://img.shields.io/badge/Rust%20%7C%20Tauri%20v2-blueviolet)
![frontend](https://img.shields.io/badge/React%20%7C%20TypeScript%20%7C%20Tailwind-38bdf8)
![status](https://img.shields.io/badge/status-oblochka%20(v0.1)-8b949e)

DSH Phone — это нативное Windows-приложение, которое поднимает локальный HTTP-мост между твоим DSH Desktop (ИИ-агент) и телефоном. Открываешь на ПК, сканируешь/вбиваешь токен на телефоне — и чатишься со своим агентом откуда угодно, пока оба устройства в одной сети Tailscale.

Никаких серверов-посредников. Всё крутится локально на твоей машине.

---

## Что умеет

- **Сам генерит конфиг и токен** при первом запуске (токен 32 hex-символа, крипто-рандом).
- **Сам определяет Tailscale IP** (десятичная 100.x сеть) и показывает адрес для телефона.
- **Авто-поднимает HTTP-сервер** на порту `8460` при запуске — кнопка старт/стоп тоже есть.
- **Тёмный дашборд** с aurora-свечением и стеклом: живой статус (порт / аптайм / счётчик запросов), карточка токена с копированием и пересозданием, встроенная инструкция подключения, карточка конфига.
- **Без утечек памяти по построению** — Rust, RAII, bounded-каналы, graceful shutdown, мьютексы без гонок.

## Технологии

| Слой | Стек | Зачем |
|------|------|-------|
| Ядро | **Rust** (tokio, axum) | детерминированная память, ноль утечек, быстрый HTTPS-мост |
| Обёртка | **Tauri v2** (WebView2) | один exe ~6 МБ, без Хрома и Ноды в рантайме |
| Фронт | **React + TypeScript + Vite + Tailwind** | красиво, типобезопасно, быстро собирается |

## Требования

**Для запуска готового exe:**
- Windows 10/11 x64
- WebView2 runtime (в Win11 уже встроен, в Win10 ставится сам при первом старте)
- Tailscale на ПК и телефоне (одна сеть)

**Для сборки из исходников:**
- Node.js 20+ (для фронта)
- Rust (stable, MSVC toolchain)
- Visual Studio Build Tools 2022 с нагрузкой **Desktop development with C++** (иначе нет `link.exe`)
- Tauri CLI (`npm install` подхватит `@tauri-apps/cli`)

## Запуск / сборка

```bash
# установить зависимости фронта
npm install

# dev-режим (окно + hot reload, devUrl localhost:1420)
npm run tauri dev

# релизная сборка (портативный exe, без инсталлера)
npx tauri build --no-bundle

# готовый exe: src-tauri/target/release/dsh-phone.exe
```

> **Важно:** собирай через `tauri build`, а не голым `cargo build`.
> Голый `cargo build` не вшивает фронтенд (`frontendDist`) в бинарь — получишь пустое окно.

## Как это работает

1. При первом запуске в `%APPDATA%\dsh-phone\config.json` появляется конфиг со свежим токеном.
2. Приложение находит Tailscale-адрес ПК (из интерфейсов `100.x.x.x`).
3. Автоматически стартует axum-сервер на `0.0.0.0:8460` (слушает все интерфейсы, поэтому виден с телефона).
4. На телефоне открываешь `http://<tailscale-ip>:8460` → вводишь токен → ты в системе.

## Конфиг

Файл: `%APPDATA%\dsh-phone\config.json`

```json
{
  "config_path": "C:\\Users\\...\\AppData\\Roaming\\dsh-phone\\config.json",
  "token": "c2125e9d7e7d53f00074743651b75cf7",
  "listen_host": "0.0.0.0",
  "listen_port": 8460,
  "staging_path": "C:\\Users\\...\\.dsh\\agents-anywhere\\bridge\\attachments\\staging",
  "tailscale_ip": "100.75.97.90",
  "connector_id": "dsh-phone",
  "created_at_unix": 1790623184
}
```

| Поле | Описание |
|------|----------|
| `token` | 32 hex-символа, крипто-рандом. Это «пароль» моста для телефона |
| `listen_host` | `0.0.0.0` — слушает все интерфейсы (чтобы телефон через Tailscale достучался) |
| `listen_port` | порт HTTP-моста, по умолчанию `8460` |
| `tailscale_ip` | определяется сам, можно поправить руками |
| `staging_path` | куда стейджить вложения (для будущего аплоада файлов) |
